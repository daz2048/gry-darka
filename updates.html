Co nowego / Release notes

Nowości i zmiany ważne dla graczy, od najnowszych. Numer wersji dotyczy konkretnej gry, nie całego portfolio. Ta historia zaczyna się od dodania centrum pomocy; starsze zmiany nie są tu jeszcze opisane.

Pomoc dla graczy i historia zmian

  • Dodano: centrum pomocy po polsku i angielsku: cele gier, sterowanie, różnice między wersjami, zapisy i rozwiązywanie problemów.
  • Dodano: linki „Pomoc” i „Co nowego” w menu portfolio oraz linki do odpowiednich instrukcji w naszych grach. Instrukcje otwierają się w nowej karcie, bez zastępowania karty gry.
  • Bez zmian: zasady rozgrywki i formaty zapisów. Oryginalny Ragdoll Archers pozostaje niezmieniony; jego instrukcja jest dostępna z centrum pomocy.

Ważne: dane gier pozostają lokalne. Klocki Podlasia 0.1 i Minecraft 0.2 nie zapisują budowli; w Minecraft 0.3 eksportuj światy jako zewnętrzne kopie. Pomoc nie dodaje obsługi telefonu ani nowych przeglądarek.

Player help and update history

  • Added: Polish/English help covering game goals, controls, version differences, saves and troubleshooting.
  • Added: Help and Updates navigation on the portfolio and contextual guide links in our games. Guides open in a new tab, keeping the game tab intact.
  • Unchanged: gameplay rules and save formats. The original Ragdoll Archers reference remains untouched; its guide is accessible from the help centre.

Limits: game data stays local. Versions 0.1 / 0.2 of the block game do not save builds; export Minecraft 0.3 worlds for external backups. Help does not add mobile or other-browser support.
