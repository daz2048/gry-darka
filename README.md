## ⌨️ Sterowanie

### Zombie (wszystkie warianty)
- **↑/W** — ruch w górę
- **↓/S** — ruch w dół
- **SPACEBAR** — bomba zwykła
- **N** — bomba atomowa
- **P** — pauza
- **F** — pełny ekran
- **R** — restart
- **M** — wyciszenie dźwięku
- **ESC** / **H** — powrót do menu głównego

### Pojedynek Zamków
- Używaj myszy do ustawiania kąta i mocy
- **SPACEBAR** — strzał
